## 變體實際定義

V-long僅將world.matchDuration=900，其他A值不變。

V-weapon僅開局每鬥士等概率發 sword/spear/hatchet/club 一把。按createArena的fighters順序，使用獨立LCG，初始state=(seed XOR 0x51ed270b)>>>0，每次state=(imul(state,1664525)+1013904223)>>>0，再取floor(state/2^32*4)。不消耗原模擬RNG。透過既有equip函式配裝、木棍用原耐久，沒有盾／弓／地面掉落或新增替換政策；棍斷後會回拳。逐seed分配留於initial，開局配裝是實驗處理，不計為玩家作弊介入。

V-hp10依 main 修正版請求：僅七個fighter.*.hp除10，標準10、熊15；拳傷、武器加值、體力與恢復仍A，牛stamina仍12。原V-x10（hp與所有傷害同乘10）取消，因同倍換單位不改血傷比，不可把這份V-hp10誤讀為同倍換算。
