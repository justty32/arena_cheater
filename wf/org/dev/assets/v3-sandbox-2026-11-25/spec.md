## 授權與範圍

本規格是 2026-11-25 提案，不是落地完成宣告。來源為 [V3 原文](../../../../../docs/design-sources/cheating-arena-v3-2026-11-23.txt)；[四題裁示](../../../../workflows/decisions.md)暫採整套戰鬥尺度、持用加值、背擊維持與完整失控三秒、豪豬蛇標準模板。真人遊戲策劃仍可改。main 補充牛體力依原文保留物種差異，不以標準體力封頂。

本批涵蓋七種鬥士基本能力、既有持用武器、狼象特性、耗體與恢復、防禦及控制時間。碰撞半徑、場地、進場位置與美術不變；一公尺直徑另開 art 切片。惠惠、種子、未實作內容及恐懼 N 等留白不填 runtime。投送、法術、資源循環、裝備耐久及彈藥不調數值。豪豬、蛇不新增特性。

## 數值與資料契約

候選差異表是唯一的新值提案，含 73 列 update / keep / add / remove、現值、A/B、單位及依據；不是第二份 runtime 設定。未列欄位全部維持基準 `46935cfd685baad74c278c8888d109fa8c6ce45d`。現行權威仍是 `src/arena/data/arena-balance.json`，本次規劃不改它。

原文鬥士與武器數值依原文；持用傷害作加值及豪豬蛇模板是使用者暫定。武器、象、fury 倍率必須換成新 hp 加值 id，不可把舊 multiplier 的單位直接改掉。新增 club 耗體，停止 fallback 一般攻擊。id、schema、loader、雙表增刪皆由 dev 寫；差異表的新名稱待 dev 確認。數值既有列待 main 另派 design，兩表不能同時雙寫。

本批實際修改／新增列的 metadata decision 使用「暫定（2026-11-25 使用者照 main 推薦；待遊戲策劃確認）」。source_path 指原文或本規格；source_locator、rationale 分清原文、暫定解讀與設計預設。keep 列僅表達依賴，不要求無故改寫其歷史依據。

## 傷害公式與精度

持用基礎傷害為 `(拳傷 + 持用武器加值 + 象木棍加值 + fury加值) × 虛弱倍率 + 嗜血加值`。拳與盾沒有武器加值；象只對現有鈍器 club 生效；狼擊殺刷新 fury，不累加層數。投送不使用此公式。

狼象先加後乘是四題裁示；嗜血仍在虛弱後加，保留現碼語意。本輪早期口頭沙盤方案曾把嗜血移到虛弱前，現已撤回並通知 dev，不納入本提案。全免招架先處理，否則沿用背擊判定及盾牌格擋倍率。正傷害在所有適用倍率完成後四捨五入至 0.01 hp，最小正傷 0.01；零傷仍零，不再保底一點。每次扣血後同樣正規化至兩位小數，最低為零，避免浮點殘血；這是可調預設，不是原文要求。既有直接法術／持續整數傷害不變。

例：標準拳背擊為 1.2；標準拳正面格擋為 0.5；虛弱拳格擋為 0.28；象木棍未加狀態為 6；熊木棍為 5。狼持劍 fury 加虛弱與嗜血為 `(1+1+3)×0.55+3=5.75`，再進行方向／防禦處理。這些是算式驗收，不是戰局實跑。

## 射程語意

原文公分換成公尺。近戰距離暫解為兩鬥士碰撞體表間隔，起手檢查 `中心距 <= 雙方半徑和 + startGap`；命中重檢 `中心距 <= 雙方半徑和 + hitGap`。命中容差暫定起手另加 0.2 m，避免 windup 後極小位移必定落空；拳與盾起手沿現況。弓採中心距，射程不另加半徑；箭飛行碰撞仍用現有掃掠及 padding，不能混同起手射程。windup、拳盾攻擊 CD 及弓彈道壽命沿用。所有體表／中心距 metadata 應明示，不以 art 的未實作尺寸推算。

## 防禦與恢復提案

推薦 A 作第一個試玩候選，不宣稱已平衡。標準體力降至十點後，原本防禦與移動門檻會把多數行為封死，因此同步縮放。格擋半點、招架一點，讓全免防禦比半傷防禦昂貴；圓盾原文耗體是 x，這兩值都是可調預設。原文圓盾 CD 半秒暫映射到招架再用間隔，不是盾拳攻擊 CD。招架威脅窗、正面判定、反震不變。

停攻滿兩秒可恢復；停移滿 2.5 秒用快回，否則慢回。A 每秒快回二、慢回一；B 只有這兩項減半，測試較重的耗盡懲罰。A 標準空槽需五秒快回或十秒慢回的有效恢復時間，另加等待門檻；這是解析推算，不是模擬結果。保留成功防禦重設 lastAttack，故長期受壓不保證能恢復。移動門檻改零而不新增移動耗體，空體力可移動但不能免費攻擊。虛弱體力上限倍率、恢復先於控制判定（倒地仍可回體）的既有行為不改。

## 控制時間

完整擊飛至可行動總計三秒是使用者暫定；分段暫定擊飛 0.35、倒地 2.3、起身 0.35 秒。轉段 deadline 必須接續前一段期限，不用當前 tick 重新起算；跨越多個期限時須推進到當前正確狀態，避免每段再多耗一幀。可恢復行動的第一個 tick 應在開始後三秒至三秒加一個 dt 以內。再次受擊、死亡、定身等既有優先序不因此免測；捕獸夾三秒定身是獨立規則。

## 戰局比較與決策限制

目前未實跑，等待 dev 的受控隔離 workspace 工具經 review 後代跑。現況／A／B 的戰長、七物種勝率、180 秒平局率、成功作弊介入次數均為「未測」，不填推測數字。沒有任何勝率或戰長證據支持推薦 A；推薦理由只有尺度一致、避免空體力卡死與較短的恢復等待。

比較使用 seed 1..100，三組相同種族席位與 tick、180 秒上限；保留逐局 seed、勝者或平局、遊戲時間及介入數。至少先跑無介入組（成功介入數固定零，不代表真人出牌空間）；若加自動介入組，必須三組共用公開、可重現的支持對象與合法操作政策，獨立報告，不能冒充人類試玩。戰長須列全局截尾平均／中位數及已結束局摘要，勝率分母固定全部局數，平局另列；100 局只供方向比較，不保證統計顯著。

開局只有拳、沒有外加裝備的比較不能驗證武器平衡，必須揭露初始裝備；武器公式、盾防及狼象交互以定向核心測試補足。若三組大多超時，先報風險與再次調整選項，不能偷偷延長比賽或加傷害。請使用者選 A、B 或先等比較再決定；設計建議先以 A 沙盤與試玩，沒有批准前不落 runtime。
