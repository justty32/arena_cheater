## 想法與 roadmap

| 事項 | 順序／狀態 | 前提 |
|------|-----------|------|
| 詐賭競技場快版 | 已落地並獲試玩接受 | 七人混戰、基本卡牌與暫停出牌保留 |
| P3 裝備戰與防禦 | 已落地 | 弓、木棍耐久／擊飛、雙手槽、招架與投送掃掠 |
| 捕獸夾 T01 | 已落地，工程驗證完成 | 使用者 2026-11-23 同意 design 預設；真人趣味與停追／反擊畫面未驗，見捕獸夾規格與後續候選 |
| P4 完整內容與 P5 平衡 | 後續 | 捕獸夾以外的武器、法術與陷阱，投注細節仍待定 |
| V3 完整數值遷移 | 待規劃 | 連動拳傷／武器倍率、耗體、恢復、防禦、移動門檻、尺寸碰撞與戰局長度；尺度調整前先開 art，不可只替換鬥士數值表 |
| 豪豬與蛇特性 | 待設計 | 不擅自補特性；狼／鹿 V2 已落地，V3 狼／象差異留後續 |
| 裁判風險／被抓後果 | 舊提案暫緩 | 新稿聚焦公開場邊介入，不自動沿用 |
| 野獸與地形法術 | 明確延期 | 使用者原文先不要生成 |

舊「擴充職業與招式」候選改以本次七鬥士及卡牌規格承接；未承諾日曆排程。故事、連線、帳號、持久養成與完整下注經濟不因本次切片自動納入。
