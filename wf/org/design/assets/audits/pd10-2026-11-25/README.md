## 分組與可重現性

採兩版本乘兩政策，共四組，每組 seed 1..100、固定 dt=1/30、支持狼、全員裸拳／無盾／無預置裝備。舊版使用前次現況基準 `7d9b7bbc621e3bb2728fe02154cb78adcdd77992` 的原始程式與數值，不套 V3 patch；新版使用已驗收 V3 commit `03b15e1f05ad5701f6c47f7fb7fcc62460c39cfd`。dev 開跑前回報兩個完整 revision，確認牌庫、費用與補石規則差異，不將舊基準的父 commit 當成基準。

依序跑新版直接法術、舊版直接法術、新版全牌、舊版全牌。每次只跑一組，全部經 arena_verify workspace 受控沙盤；只加隔離 runner／量測，不改規則、不注入牌石、不覆寫歷史證據。保留 runner、完整 revision、實際數值來源、命令、verify JSON、清理結果、逐局與逐窗口資料；大型條列成果遵守專案資料檔契約。若時間不足優先交前三組，第四組未完成必須標明。

兩版本各用其原生時限與終局規則，不能為求相同時間擅改舊版。除全局結果外，另報共同早期觀察區間（起始至舊版時限）的數據，以及兩版本同 seed 都仍能介入的配對窗口結果，避免長戰局累積更多失敗窗口就被誤判為啟動退化。這是版本整體比較，不能單靠它辨識某一參數的因果效果。

## 政策契約

共同規則：首次 t>=5，其後每 5 遊戲秒一個窗口，每窗口最多成功出一張；狼死亡或引擎不接受介入即停止出牌，戰局仍跑到正常終場。用原生支付、驗證及出牌 API，不用棄牌換石；沒有成功就不改手牌或資源。記錄實際時間，不用浮點等號排窗口。

直接法術完全沿用前次政策：手牌順序找第一張可支付且合法的 lightning／lightning-rain／divine-wrath；活熊優先，否則活敵最高精確 hp 比例，同分用初始鬥士順序；範圍牌落在該敵中心。不得因支付失敗就停止檢查後面的牌。

全牌政策沿手牌順序檢查所有牌，選第一張有可支付合法動作的牌。傷害／負面法術先試上述敵人順序；治療先試受傷狼，再按缺血比例由高至低試活鬥士；增益先狼再依初始順序試其他活鬥士。裝備先試狼中心，投擲消耗品與陷阱先試敵人中心，再試其他活鬥士中心及固定場內格點；使用 API 驗證，不越過射程或空圈限制。裝備若狼中心不合法，再試其他活鬥士初始順序中心及固定格點；這允許裝備落到其他鬥士附近，不代表最佳支持策略。固定格點間距 1m，外圈 y=-8..8、內圈 x=-8..8，僅取 x*x+y*y<=ARENA_RADIUS²；重複座標去重保留首次，各版本一致。有限目標搜尋失敗須標為「政策候選目標皆不合法」，不能宣稱連續場地上不存在合法位置；另報此類數量。

無目標牌正常施放；謹慎思考從已揭示候選取第一張、完成選牌並恢復原交戰狀態，不因選牌另送額外出牌窗口。直覺正常揭示但不改選牌排序。全牌也不棄牌換石：此批隔離的是牌型限制，不同時測資源交換政策。dev 若發現未涵蓋的卡牌機制，先回報補契約，不默默略過或自創最佳策略。這不是最佳或真人玩法，也不能因全牌結果好就認定經濟無問題。

dev 開跑前讀碼／逐表回報：兩版原生 card-catalog、resources、engine-cards 無差異，牌庫組成、起手牌石、成功出牌補石、支持者擊殺補石、費用與思考／直覺規則相同。這是靜態比對，不是實跑結論；戰鬥與時限會影響收入時點，仍待時間線驗證。無牌冷卻，預期該診斷類為零。

## 窗口診斷與對帳

每個窗口保存 seed、版本／政策、遊戲時間、階段、狼生命與存活、按順序的手牌、五色庫存、檢查的動作與 API 拒絕理由、選中牌與目標、付款及成功後手牌／石頭。逐候選記總石數是否滿足總費用、指定色是否滿足、目標是否合法、是否冷卻；多個條件同時不滿足全部保留。

窗口主因互斥，按以下檢查順序歸類：成功；沒有政策牌；有政策牌但沒有合法目標候選；有合法目標但全被冷卻擋住；其餘可執行候選全部總石數不足；至少一張總數足夠但指定色不足；其他（附原始理由）。主因依全手牌的可用候選判定，不取第一張拒絕原因代替全窗口。若直接法術沒有冷卻機制，該類應為零並說明，不拿換石冷卻充數。

預定窗口若因狼死亡、清算或已終局而未執行，另記跳過原因，不混入失敗分母。各主因合計須等於已執行窗口，成功次數須等於有效出牌事件；同時報「至少一次成功的局數」、首次成功時間及未成功局數，不能用大量重複失敗窗口取代獨立對局樣本。

## 魔法石與擊殺時間線

每局保存起手五色石、起手牌，以及所有收入／支出事件的時間、來源、色別、數量和前後庫存。收入至少區分起手、成功出牌補石、支持者擊殺補石；支出分出牌付款與其他，其他須明示。不以相鄰快照的淨變化當成收入，避免付款與補石同幀互相抵消。檢查逐色「起手＋收入－支出＝末態庫存」，補牌／抽牌另記，勿把牌誤算為石。

記錄每次鬥士死亡、擊殺來源、是否支持者取得獎勵、狼死亡時間。比較總擊殺與支持者擊殺的首次時間、次數及間隔；無擊殺／無成功者保留為未發生，不從平均分母排掉後當成全局值。指出較長戰局可能延後收入，但不預設死亡總數一定較少；場邊法術擊殺未必帶來支持者補石。
