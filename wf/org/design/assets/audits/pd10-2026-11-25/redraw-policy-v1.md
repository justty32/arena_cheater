## 目的與組別

依 main 2026-11-25 授權，檢驗既有換石機制是否緩解全牌政策的持續卡色，不修改任何遊戲數值。只跑一組：V3 commit `03b15e1f05ad5701f6c47f7fb7fcc62460c39cfd`、seed 1..100，沿用前次新版全牌的初始化、dt、窗口、目標、支付與思考選牌規則；新增下列換石策略。與前次第三組固定證據比較，不重跑基準、不測第二種門檻，以保留核對時間。目標 16:10 台灣時間前交結論，不足則回報已完成部分。

## 確定性操作

每個已執行窗口仍先找原全牌政策可支付且合法的牌；能出則正常出牌，連續卡色計數歸零，不換石。不能出時按原主因分類；僅當主因為 colored-stones 才累加連續計數，其他主因歸零。跳過窗口不累加也不歸零，狼死亡或結算後不再操作。

連續兩個已執行窗口卡色，且原生換石條件允許時，呼叫 redrawStones：棄當時手牌順序第一張，選當時庫存順序第一顆石，只換這一顆；不按顏色或牌價優化，不查看隱藏牌序。這是可重現的簡單試驗政策，不是最佳解。只用原生 API 的費用、補石補牌及冷卻，不注入資源、不繞過驗證。

一次窗口最多一個有效動作：成功換石後不在同窗追加出牌，連續計數歸零，等待下一原定窗口。冷卻、無手牌或無石導致無法換石時保留已達門檻的卡色計數，下次卡色窗口再試；失敗不得改狀態。換石後抽到的牌也不在當窗使用。

## 指標與對帳

卡色窗口數按「換石前、正常出牌檢查結果」計數，成功換石不能把該窗改成成功出牌，避免以分類改名製造改善。另記換石嘗試、成功、拒絕原因、棄牌與石色，以及換石後首次成功出牌時間。原成功次數／成功局數只算 playCard，不算 redrawStones；零成功局也是零正常出牌，另報零有效動作局數。

與前次新版全牌並排：窗口數、卡色窗口與占比、末個可介入窗口仍卡色的局數、零正常出牌局數、正常出牌次數及成功局數、戰長分布。另報同 seed 共同可介入窗口的正常出牌／卡色，避免策略改變生存時長後全局分母不同。末窗即使換石成功仍依換石前判定卡色，另報「末窗換石成功但未再觀察」局數，不當成已解套或永久死鎖。

收支時間線新增 redraw-payment／redraw-income，和正常出牌、支持殺、起手分開；若原生內部共用 consumeCard，量測須在呼叫來源標記，不能把換石棄牌當成功施法。逐色每事件與末態對帳，正常付款事件數對正常出牌、換石付款事件數對換石成功；不得只看淨變化。保留每 seed 的零啟動與末窗卡色配對差異，尤其核對原先六個零啟動 seed。

## 執行與交付

dev 只在 arena_verify workspace 受控隔離副本量測，一次一組，不改正式 src/tests、不改基準證據、不直接跑 Node。保存 runner、插樁差異、來源 revision、verify 與清理證據；摘要、配對、核對結論放 wf/org/dev/assets/，大量 raw 放 /tmp 並在 manifest 標明外部路徑與 SHA256，不稱永久備份。先回覆契約有無 API 空白，完成後交 design 核對及更新 PD10。

判讀只能說本次簡單政策在固定樣本的效果；換石同時改變手牌、色石與 RNG 消耗，不可把差異全歸因補石量或某一顏色。沒有測最佳策略、真人操作成本或有效傷害，不因出牌增加就決定經濟平衡已接受。
