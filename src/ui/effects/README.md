# 戰鬥特效

[effects.ts](../effects.ts) 是外部入口，統一管理圖層順序、重置及降低動態效果偏好；各圖層只讀戰鬥狀態，以相同遊戲時間呈現。

| 檔案 | 職責 |
|------|------|
| [targets.ts](targets.ts) | 攻擊來源與目標的連線、選取高亮 |
| [projectiles.ts](projectiles.ts) | 箭矢、火球及魔力彈的 SVG 與飛行內插 |
| [impacts.ts](impacts.ts) | 命中、近戰刀弧、治療與傷害數字，依事件 ID 避免重播 |
| [svg.ts](svg.ts) | SVG 建立、棋子中心座標及進度限制 |

圖層由下而上為目標線、投射物、命中效果。介面不修改傷害、資源或事件；暫停、倍速及重開由既有戰鬥狀態驅動。
